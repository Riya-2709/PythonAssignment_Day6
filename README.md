# Expense Tracker CLI

## Description

Expense Tracker is a Python command-line application used to manage daily expenses.

## Features

- Add Expense
- View Expenses
- Delete Expense
- Calculate Total Spending
- Store expenses using JSON file handling
- Validate user input
